# Micro·poemas bolivianos

Generador de micro-poemas que combina al azar **bolivianismos reales** del
*Diccionario de la lengua española* (23.ª ed., 2014), recopilación de
**Raúl Rivadeneira Prada**.

Inspirado en [art-words.net](https://www.art-words.net) (Eva Beierheimer &
Miriam Laussegger), trasladado del lenguaje del arte al habla boliviana.

> ⚠ Proyecto en construcción. El programa cuida la gramática (concordancia de
> género y número) pero no entiende el significado de las palabras, así que
> algunos versos pueden sonar extraños o tener errores.

## Archivos

- `index.html` — la página
- `data.js` — el vocabulario (239 bolivianismos)
- `bus.png` — imagen de cabecera

## Ver en local

Abrí `index.html` en el navegador (doble clic), o con un servidor:

```bash
python3 -m http.server 8000
# luego abrí http://localhost:8000
```

## Publicar en GitHub Pages

Sube los archivos a un repositorio y activá **Settings → Pages →
Branch: main / root**. La página quedará en
`https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
